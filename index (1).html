動態粒子背景

利用 Canvas 繪製粒子與連線，加入柔和漂移，創造有層次的科技感背景。

Canvas
function animate() {
  ctx.clearRect(0, 0, width, height);
  particles.forEach(particle => {
    particle.x += particle.vx;
    particle.y += particle.vy;
    drawParticle(particle);
  });
  requestAnimationFrame(animate);
}
